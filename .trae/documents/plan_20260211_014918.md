# MakanX Rebuild Design Plan

This plan outlines the architecture for rebuilding MakanX from scratch as a monorepo.

## 1. Monorepo Structure
We will use **npm workspaces** (compatible with TurboRepo if needed later) to manage dependencies.

```text
/
├── package.json          # Root package.json (workspaces defined)
├── apps/
│   ├── web/              # Frontend: React + Vite + TS + Tailwind
│   │   ├── src/
│   │   ├── vite.config.ts
│   │   ├── tailwind.config.js
│   │   ├── .env.example
│   │   └── package.json
│   └── api/              # Backend: Node.js + Express + TS
│       ├── src/
│       │   ├── controllers/
│       │   ├── middleware/
│       │   ├── routes/
│       │   ├── services/
│       │   └── index.ts  # Entry point
│       ├── prisma/
│       │   └── schema.prisma
│       ├── .env.example
│       └── package.json
└── packages/
    └── shared/           # Shared types and constants
        ├── src/
        │   ├── index.ts  # Exports types, Zod schemas, etc.
        │   └── types.ts
        ├── package.json
        └── tsconfig.json
```

## 2. Environment Variables (.env.example)

**apps/web/.env.example**
```ini
# API URL for backend requests
VITE_API_URL=http://localhost:3001/api

# Socket.IO URL (usually same as API in dev)
VITE_SOCKET_URL=http://localhost:3001
```

**apps/api/.env.example**
```ini
# Server Configuration
PORT=3001
NODE_ENV=development

# Database (Neon PostgreSQL)
DATABASE_URL="postgresql://user:password@host:port/dbname?sslmode=require"

# Authentication
JWT_SECRET="super-secret-key-change-me"
JWT_EXPIRES_IN="7d"

# Client URL (for CORS)
CLIENT_URL=http://localhost:5173

# Webhook Secrets (for Google Apps Script security)
GOOGLE_WEBHOOK_SECRET="secret-token-from-google-script"
```

## 3. Prisma Schema Draft

```prisma
// apps/api/prisma/schema.prisma

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

enum Role {
  CUSTOMER
  VENDOR
  ORGANIZER
}

enum OrderStatus {
  PENDING
  PREPARING
  READY
  COMPLETED
  CANCELLED
}

enum ApplicationStatus {
  PENDING
  APPROVED
  REJECTED
}

model User {
  id        String   @id @default(uuid())
  email     String   @unique
  password  String   // Hashed
  name      String
  role      Role     @default(CUSTOMER)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  // Relations
  vendorProfile VendorProfile?
  orders        Order[]
  managedEvents Event[]        @relation("OrganizerEvents")
}

model Event {
  id          String   @id @default(uuid())
  name        String
  description String?
  startDate   DateTime
  endDate     DateTime
  location    String?
  organizerId String
  organizer   User     @relation("OrganizerEvents", fields: [organizerId], references: [id])
  
  booths      Booth[]
  applications VendorApplication[]
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

model VendorProfile {
  id           String   @id @default(uuid())
  userId       String   @unique
  user         User     @relation(fields: [userId], references: [id])
  businessName String
  description  String?
  
  menuItems    MenuItem[]
  booths       Booth[]
  orders       Order[]  @relation("VendorOrders")
}

model VendorApplication {
  id             String            @id @default(uuid())
  eventId        String
  event          Event             @relation(fields: [eventId], references: [id])
  applicantName  String
  applicantEmail String
  businessName   String
  googleFormData Json?             // Store full payload from Google Form
  status         ApplicationStatus @default(PENDING)
  createdAt      DateTime          @default(now())
}

model Booth {
  id        String   @id @default(uuid())
  eventId   String
  event     Event    @relation(fields: [eventId], references: [id])
  vendorId  String?
  vendor    VendorProfile? @relation(fields: [vendorId], references: [id])
  name      String   // e.g., "A1", "B2"
  status    String   // "AVAILABLE", "OCCUPIED"
}

model MenuItem {
  id             String        @id @default(uuid())
  vendorId       String
  vendor         VendorProfile @relation(fields: [vendorId], references: [id])
  name           String
  description    String?
  price          Decimal
  imageUrl       String?
  isAvailable    Boolean       @default(true)
  orderItems     OrderItem[]
}

model Order {
  id          String      @id @default(uuid())
  customerId  String
  customer    User        @relation(fields: [customerId], references: [id])
  vendorId    String
  vendor      VendorProfile @relation("VendorOrders", fields: [vendorId], references: [id])
  status      OrderStatus @default(PENDING)
  totalAmount Decimal
  createdAt   DateTime    @default(now())
  updatedAt   DateTime    @updatedAt
  
  items       OrderItem[]
}

model OrderItem {
  id         String   @id @default(uuid())
  orderId    String
  order      Order    @relation(fields: [orderId], references: [id])
  menuItemId String
  menuItem   MenuItem @relation(fields: [menuItemId], references: [id])
  quantity   Int
  price      Decimal  // Snapshot of price at time of order
}

model InviteToken {
  id        String   @id @default(uuid())
  token     String   @unique
  role      Role
  eventId   String?  // If inviting a vendor to a specific event
  isUsed    Boolean  @default(false)
  expiresAt DateTime
}
```

## 4. API Route List & Contracts

### Authentication
- `POST /auth/register` - `{ email, password, name, role }` -> `{ token, user }`
- `POST /auth/login` - `{ email, password }` -> `{ token, user }`
- `GET /auth/me` - (Auth Header) -> `{ user }`

### Webhooks (Google Forms)
- `POST /webhooks/vendor-application`
  - Body: Google Form payload
  - Logic: Creates `VendorApplication` record.

### Events (Public/Organizer)
- `GET /events` - List active events
- `POST /events` - (Organizer only) Create event

### Vendor Management
- `GET /vendor/applications` - (Organizer) List pending apps
- `POST /vendor/applications/:id/approve` - (Organizer) Approve & potentially generate InviteToken
- `GET /events/:eventId/booths` - Get booth map/status

### Menu & Orders
- `GET /vendors/:id/menu` - Public
- `POST /orders` - (Customer) `{ vendorId, items: [{id, qty}] }` -> Emit Socket event to Vendor
- `GET /orders` - (Customer/Vendor) List own orders
- `PATCH /orders/:id/status` - (Vendor) Update status -> Emit Socket event to Customer

## 5. Deployment Notes

### Frontend (Vercel)
1.  **Framework Preset**: Vite
2.  **Root Directory**: `apps/web`
3.  **Build Command**: `npm run build` (or `cd ../.. && npm install && npm run build` if using root)
4.  **Output Directory**: `dist`
5.  **Environment Variables**: Set `VITE_API_URL` to the Render backend URL.

### Backend (Render)
1.  **Type**: Web Service
2.  **Root Directory**: `apps/api` (or root if using monorepo build command)
3.  **Build Command**: `npm install && npm run build` (Run from root usually, or scope to api)
4.  **Start Command**: `npm start` (which runs `node dist/index.js`)
5.  **Environment Variables**:
    - `DATABASE_URL`: Connection string from Neon.
    - `JWT_SECRET`: Secure random string.
    - `NODE_ENV`: production.
